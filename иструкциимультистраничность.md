ВНИМАНИЕ: Проведи полный архитектурный рефакторинг проекта под мульти-тенантность (Multi-Tenant SaaS) на Vercel.   
Визуальный стиль, дизайн, темную тему, Glassmorphism и утвержденную верстку НЕ ТРОГАТЬ.  
Твоя задача — сделать так, чтобы один задеплоенный сайт генерировал независимые персональные страницы для сотен автосервисов по динамическому URL вида: \`домен.vercel.app/\[slug\]\`.

Реализуй следующую архитектуру от и до:

**\================================================== 2\. ХЕЛПЕР ДАННЫХ (lib/getCompany.ts):**

Создай функцию `getCompany(slug: string)`:

* Ищет объект в `data/companies.json` по совпадению `slug`.  
* Если slug не найден или это главная страница `/`, возвращает первую компанию из списка как дефолтную, либо вызывает `notFound()`.  
* Экспортируй строгий TypeScript интерфейс `Company`.

# **\================================================== 3\. ДИНАМИЧЕСКИЙ РОУТИНГ (app/\[slug\]/page.tsx):**

* Перенеси всю логику лендинга в `app/[slug]/page.tsx`.  
* Сделай страницу серверным компонентом, который принимает `params: { slug: string }`.  
* Получай данные через `const company = getCompany(params.slug)`.  
* Передавай объект `company` пропсами во все дочерние компоненты:  
  * `<Header company={company} />` (подставляет телефон, адрес, город).  
  * `<Hero company={company} />` (подставляет динамический H1 с городом).  
  * `<Calculator company={company} />` (считает цены на базе `company.prices`).  
  * `<BeforeAfterSlider company={company} />` (выводит кейсы этой точки).  
  * `<LeadModal company={company} />` (передает slug и данные сервиса в форму отправки).  
* Настрой `generateStaticParams()` для автоматической статической генерации (SSG) всех slug из `companies.json` при сборке на Vercel.

# **\================================================== 4\. ГЛАВНАЯ СТРАНИЦА (app/page.tsx):**

* В `app/page.tsx` настрой автоматический рендеринг первой компании из списка либо редирект на `/pdr-kovaleva-krd`, чтобы при переходе на чистый домен сайт не отдавал 404 ошибку.

# **\================================================== 5\. БЕЗОПАСНОСТЬ И ОТПРАВКА ЛИДОВ (app/api/lead/route.ts):**

* Создай POST эндпоинт `/api/lead`.  
* Он принимает: `slug`, `phone`, `carModel`, `calculatedPrice`, `photoUrl`.  
* Находит компанию по `slug`.  
* ПРОВЕРКА СТАТУСА:  
  * Если `company.isActive === false`: сообщение помечается как `[ТЕСТ / DEMO]` и отправляется в тестовый бот администратора (или логируется в консоль). Владелец автосервиса НЕ получает лид, пока не оплатил\!  
  * Если `company.isActive === true` и заполнен `company.telegramChatId`: заявка отправляется напрямую через Telegram Bot API на chat\_id этого мастера.

# **\================================================== РЕЗУЛЬТАТ:**

Проект должен собираться командой `npm run build` без ошибок типов TypeScript. Любая новая компания, добавленная в `companies.json`, должна мгновенно открываться по ссылке `localhost:3000/[slug]` без создания новых страниц вручную.
